Three steps.

If you already use a coding agent CLI, you’re basically done.

1

Run it on a dirty repo

From any project with uncommitted changes:

npx @khosla/preflight
2

Read the verdict

Browser opens with what changed + findings. Or use agent mode:

npx @khosla/preflight --json --auto
3

Fix and re-run

Exit 0 = approved. Exit 2 = fix findings, then run again (delta re-review is automatic).

What you get.

Not another noisy bot. A calm local gate between agent output and ship.

Explain

Short story of the change, not a raw file dump.

Judge

Blockers and should-fix items with agreement when multiple CLIs exist.

Act

Executable findings for agents. Approve or request changes for humans.
